# 음성 팩 기술자 — release.ps1이 읽어 릴리스 매니페스트의 audio_* 줄을 만든다.
#
#   pack   팩 ID. 사용자 오디오 캐시의 표식(teamradio56_audio_pack.txt)과 다르면
#          설정 화면에 [음성 팩 업데이트]가 뜬다
#   tag    팩 zip이 자산으로 올라가 있는 릴리스 태그 = audio-<pack> (프리릴리스, latest 아님).
#          릴리스 매니페스트는 이 태그를 가리킨다 — 이 릴리스는 지우거나 자산을 바꾸지 말 것
#   asset  zip 이름,sha256,바이트 수 (설치 순서대로 한 줄씩). zip 루트에 *.wav만 둔다
#
# 새 팩(멘트 집합이 바뀔 때만): GitHub Actions → audio-pack 을 새 pack ID로 실행하면
# 렌더·zip·audio-<pack> 릴리스·이 파일의 pack/tag/asset 줄 커밋까지 한다 (주석은 그대로 둔다).
