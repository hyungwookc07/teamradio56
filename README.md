# FFB 최적화 랩

심레이싱 포스 피드백(FFB)을 최적화하는 원페이지 웹 툴입니다. 빌드나 설치 없이
`index.html`을 브라우저로 열면 바로 동작하며, 모든 계산은 브라우저 안에서만 이뤄집니다
(서버 전송 없음).

## 기능

1. **장비별 시작 세팅 추천 (STEP 01)** — 휠베이스(공칭 토크)와 게임, 체감 강도 취향을
   고르면 커뮤니티에서 통용되는 시작점 세팅을 계산합니다.
   지원 게임: iRacing, ACC, Assetto Corsa, rFactor 2 / LMU, AMS2, F1 24/25, GT7.
2. **클리핑 시뮬레이터 (STEP 02)** — 20초짜리 합성 랩 신호에 게인을 적용해 클리핑이
   생기는 과정을 파형·히스토그램으로 보여주고, 클리핑 시간 비중 / 디테일 손실 /
   권장 게인을 계산합니다.
3. **텔레메트리 검증 (STEP 03)** — iRacing(MoTeC i2 내보내기) 등의 CSV를 올리면
   토크/FFB 컬럼을 자동 인식해 피크·백분위(P99.5)·클리핑 비율을 계산하고,
   iRacing이라면 권장 max force 값을 직접 제안합니다. 샘플 데이터 버튼으로
   파일 없이도 흐름을 볼 수 있습니다.

## 사용법

```
git clone <이 저장소>
브라우저로 index.html 열기
```

## 원리 요약

FFB는 정보 채널입니다. 게임이 요청하는 힘이 휠 출력 한계(100 %)를 넘으면 신호
꼭대기가 잘리는 **클리핑**이 생기고, 잘린 구간에서는 그립 한계·연석·노면 디테일이
사라집니다. 이 툴은 "신호의 P99.5가 출력 한계 바로 아래에 오도록" 게인/맥스포스를
맞추는 것을 기준으로 권장값을 계산합니다 (시간 비중 0.5 % 미만의 순간 클리핑은 허용).

## 한계

- 게임별 수치는 커뮤니티 통용 **시작점**이며 게임 버전에 따라 달라질 수 있습니다.
- 휠 최대 토크는 제조사 공칭값 기준입니다.
- 시뮬레이터 파형은 교육용 합성 신호이며 실제 물리 엔진 출력이 아닙니다.
