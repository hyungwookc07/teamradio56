# 설치 가이드 — teamradio56 SimHub 플러그인

르망 얼티밋(LMU)에서 teamradio56을 처음 설치하는 순서예요. 전부 해도 10분이면 끝나요.
(English readers: the essential install steps are in [README.md](../README.md#install).)

순서는 이래요.

1. LMU 설정 켜기 (게임 쪽)
2. teamradio56 플러그인 설치 (SimHub 쪽)
3. 음성 팩 받기
4. 동작 확인

준비물: Windows 10/11, 르망 얼티밋 1.2 이상, [SimHub](https://www.simhubdash.com/).
파이썬은 필요 없어요. rF2 공유 메모리 플러그인(DLL)은 이제 선택이에요.
LMU가 1.2보다 오래됐거나 연결이 안 될 때만 [아래](#선택-rf2-공유-메모리-플러그인)처럼 설치하세요.

## 1. LMU 설정 켜기 (한 번만)

LMU 1.2부터는 게임이 직접 공유 메모리로 데이터를 내줘요. teamradio56은 그걸 읽기
때문에 게임에 따로 깔 건 없고, 설정 하나만 켜면 돼요.

1. LMU에서 **Settings → Gameplay**를 열고 **Enable Plugins**를 켜요.
2. LMU를 **완전히 껐다가 다시 켜요.** 이 설정은 게임을 다시 시작해야 적용돼요.
   켜 놓고 바로 세션에 들어가면 아직 연결되지 않아요.

> 4단계에서 연결을 확인해요. 세션에 들어가도 계속 **○ 게임 대기 중**이면
> [rF2 공유 메모리 플러그인](#선택-rf2-공유-메모리-플러그인)을 설치하세요.

## 2. teamradio56 플러그인 설치

1. [최신 릴리스](https://github.com/hyungwookc07/teamradio56/releases/latest)에서
   `teamradio56-plugin-x.y.z.zip`만 받으면 돼요. 다른 파일은 필요 없고, 음성 팩은
   플러그인 안에서 받아요. 압축을 풀면 DLL이 두 개 있어요.
   - `TeamRadio56.Core.dll`
   - `TeamRadio56.SimHub.dll`

   받은 zip이 릴리스에 올라간 파일과 똑같은지 확인하고 싶으면
   [선택: 받은 zip 확인하기](#선택-받은-zip-확인하기)를 보세요. 안 해도 돼요.
2. **SimHub을 끄고**, 두 DLL을 **SimHub 설치 폴더 바로 아래**에 복사해요.
   하위 폴더에 넣으면 안 돼요. 기본 경로는 이래요.

   ```
   C:\Program Files (x86)\SimHub\
   ```

3. SimHub을 켜면 **새 플러그인을 활성화할지 묻는 창**이 떠요. **teamradio56**에
   체크하세요. 창이 안 뜨면 SimHub **Settings → Plugins**에서 직접 켜면 돼요.
4. SimHub **왼쪽 메뉴에 teamradio56**이 생기면 성공이에요. 누르면 설정 화면이 열려요.

> 설정 화면은 처음에 한국어로 나와요. 맨 위 언어 선택에서 **English**로 바꿀 수 있어요.
> 항목(또는 옆의 **ⓘ**)에 마우스를 올리면 설명이 떠요.
>
> 설정은 DLL 옆의 `teamradio56.settings.txt`에, 로그는 같은 폴더의 `teamradio56.log`에 저장돼요.

## 3. 음성 팩 받기

음성 팩이 없으면 무전이 **소리 없이 자막으로만** 나와요. 설정 화면 맨 위에 빨간 안내가
떠 있을 거예요.

1. 설정 화면 아래쪽 **업데이트** 섹션으로 가요.
2. **[음성 팩 업데이트]**를 누르고, 확인 창에서 **예**를 눌러요.
   - 버튼이 꺼져 있으면 먼저 **[업데이트 확인]**을 누르세요. (**시작 시 확인**이
     켜져 있으면 SimHub을 켜고 15초쯤 뒤에 자동으로 확인해서, 보통은 바로 누를 수 있어요.)
   - 크기는 200 MB가 안 돼요. 받는 동안 진행률이 보이고 **[취소]**할 수 있어요.
     주행 중이 아닐 때 받는 걸 추천해요.
3. "음성 팩 … 설치 완료 — 엔진을 다시 시작해 바로 적용했습니다."가 뜨면 끝이에요.
   SimHub을 재시작할 필요는 없어요.

음성 팩은 DLL 옆의 `audio_cache` 폴더에 설치돼요. 지금 쓰는 폴더는 **엔진** 섹션 상태 줄의
**ⓘ**에 마우스를 올리면 보여요. 다른 곳에 두고 싶으면 **엔진** 섹션의
**음성 팩 폴더**에 경로를 넣고 **[엔진 재시작]**을 누르세요.

## 4. 동작 확인

1. **상태** 섹션의 **[테스트 발화]**를 눌러요. Windows 기본 오디오 장치로
   *"Box box, box box."*가 들리고, 버튼 아래에 "테스트 발화: 음성 팩으로 재생"이 뜨면 정상이에요.
   (이 버튼은 **음성 출력**을 꺼 둬도 소리를 내요.)
2. LMU를 켜고 세션(연습주행이라도)에 들어가요.
3. **상태**의 램프가 **○ 게임 대기 중**에서 **● LMU 연결됨**으로 바뀌고, 순위·랩·연료가
   보이면 정상이에요. 무전이 나오면 **최근 무전**에 쌓여요.
4. 램프 바로 아래 줄에 데이터를 어디서 읽는지 나와요.
   - **데이터: LMU 내장 공유 메모리 — rF2 DLL 없이 동작 중**: 1단계 설정으로 연결됐어요.
   - **데이터: LMU 내장 공유 메모리 (피트 제한속도·페널티 메시지는 rF2 DLL에서 보충)**:
     rF2 플러그인도 깔려 있어서 거기 없는 두 가지만 보충하는 중이에요.
   - **데이터: rF2 공유 메모리 플러그인 (DLL)**: LMU 내장 데이터를 못 찾아 rF2 플러그인으로
     읽고 있어요. 그대로 써도 돼요.
   - LMU를 켜고 메뉴에 있을 때 **LMU 내장 공유 메모리를 찾았어요 — 세션에 들어가면 연결돼요.**가
     보이면 1단계 설정은 잘 된 거예요. 게임을 끄면 몇 초 안에 Enable Plugins 안내로 돌아가요.
   - **LMU 내장 공유 메모리의 값이 예상과 달라 쓰지 않습니다**: 1단계 설정은 된 거예요 (데이터를
     찾아서 읽어 봤어요). 게임 업데이트로 형식이 바뀐 듯해요 — 아래 문제 해결을 보세요.

> 트래픽·스포터 콜은 기본값으로 **레이스에서만** 나와요. 연습에서 조용한 건 정상이에요.

## 업데이트와 삭제

- **업데이트**: 설정 화면 **업데이트** 섹션의 **[업데이트 확인]** →
  **[플러그인 업데이트]**(끝나면 SimHub 재시작) 또는 **[음성 팩 업데이트]**.
  버튼을 누르기 전에는 아무것도 설치하지 않아요.
  - 설정 화면에 **업데이트** 섹션이 없다면(아주 예전 버전) 위 2번처럼
    최신 릴리스를 한 번만 손으로 설치하세요. 그다음부터는 설정 화면에서 돼요.
- **이전 버전으로**: 업데이트는 새 버전으로만 가요. 릴리스 페이지에서 원하는 버전 zip을 받아
  SimHub을 끈 상태로 DLL 두 개를 덮어쓰세요.
- **삭제**: SimHub을 끄고 SimHub 폴더에서 `TeamRadio56.Core.dll`, `TeamRadio56.SimHub.dll`
  (그리고 남아 있다면 `TeamRadio56.*.dll.old*`, `teamradio56_backup.txt`, `teamradio56_update` 폴더), `teamradio56.settings.txt`,
  `teamradio56.log`, `audio_cache` 폴더를 지우면 돼요.

> 예전에 파이썬 단독 실행판을 쓰면서 LMU Steam 시작 옵션에 `launch_with_lmu.bat`을
> 넣었다면 지우세요. 그대로 두면 무전이 두 번(서로 다른 목소리로) 나올 수 있어요.

## 선택: 받은 zip 확인하기

꼭 할 필요는 없어요. 받은 zip이 릴리스에 올라간 파일과 똑같은지 직접 확인하고 싶을 때만 하세요.

릴리스 페이지 본문의 **파일 검증** 부분에 zip의 SHA-256 값이 있어요. 게시하기 전에
Microsoft Defender로 검사한 결과도 함께 적혀 있어요. (예전 릴리스에는 이 부분이 없어요.)

1. zip을 받은 폴더의 빈 곳을 오른쪽 클릭하고 **터미널에서 열기**를 눌러요.
   (Windows 10은 Shift를 누른 채 오른쪽 클릭 → **여기에 PowerShell 창 열기**)
2. 아래처럼 입력해요. `x.y.z`는 받은 버전으로 바꾸세요.

   ```powershell
   Get-FileHash .\teamradio56-plugin-x.y.z.zip -Algorithm SHA256
   ```

3. 나온 **Hash** 값이 릴리스 페이지의 값과 같으면 돼요. 대소문자는 상관없어요.
   다르면 설치하지 말고 다시 받아 보세요.

[GitHub CLI](https://cli.github.com/)에 로그인해 쓰고 있다면, 이 저장소의 GitHub Actions가
만든 파일인지도 확인할 수 있어요. **Verification succeeded!**가 나오면 돼요.

```
gh attestation verify teamradio56-plugin-x.y.z.zip -R hyungwookc07/teamradio56
```

## 선택: rF2 공유 메모리 플러그인

르망 얼티밋은 rFactor 2 엔진 기반이라 The Iron Wolf가 만든
**rF2 Shared Memory Map Plugin**도 쓸 수 있어요. 예전 버전의 teamradio56은 이 플러그인이
꼭 있어야 했지만, 이제는 대체 수단이에요. 이럴 때만 설치하세요.

- LMU가 1.2보다 오래됐을 때
- 1단계를 했는데도 세션에서 계속 **○ 게임 대기 중**일 때
- 상태에 "LMU 내장 공유 메모리의 값이 예상과 달라 쓰지 않습니다"가 나올 때 (게임 업데이트로
  형식이 바뀐 경우)

이미 깔려 있다면 그대로 두세요. 둘 다 있으면 teamradio56은 LMU가 직접 내주는 데이터를
쓰고, 거기 없는 **피트 제한속도**와 **페널티 메시지**만 이 플러그인에서 가져와요. 플러그인이
없으면 피트 리미터 경고는 기본 제한속도로 판단하고, 페널티 콜은 페널티 종류를 말하지 못해요.

### DLL 받기

- 배포처: https://github.com/TheIronWolfModding/rF2SharedMemoryMapPlugin (Releases)
- 파일: `rFactor2SharedMemoryMapPlugin64.dll`

> 다른 심레이싱 툴(CrewChief, 각종 대시 앱 등)을 쓰고 있다면 이미 깔려 있을 수 있어요.
> 아래 경로에 DLL이 있는지 먼저 확인하세요.

### DLL 복사

게임 설치 폴더(아래에서는 `<게임 폴더>`라고 할게요)의 `Plugins` 폴더에 복사해요.
`<게임 폴더>`는 보통 `<Steam 라이브러리>\steamapps\common\Le Mans Ultimate`예요.

```
<게임 폴더>\Plugins\rFactor2SharedMemoryMapPlugin64.dll
```

### 플러그인 켜기

1. DLL을 복사한 상태로 게임을 한 번 켰다가 끄세요. 그래야 설정 항목이 자동으로 생겨요.
2. 게임을 끈 상태에서 `<게임 폴더>\UserData\player\CustomPluginVariables.JSON` 파일을 열어
   `"rFactor2SharedMemoryMapPlugin64.dll"` 항목을 찾고, `" Enabled"` 값을 `1`로 바꿔요.

이렇게 보이면 돼요 (붙여넣지 말고 값만 바꾸세요. 같은 항목의 다른 줄은 그대로 두면 돼요).

```
  "rFactor2SharedMemoryMapPlugin64.dll": {
    " Enabled": 1,
    ...
```

⚠️ **`" Enabled"`에서 `Enabled` 앞(따옴표 안)의 공백 한 칸은 오타가 아니에요. 원래 이렇게 써야 해요.**
공백을 지우면 게임이 설정을 못 알아봐요.

- 게임이 켜져 있을 때는 이 파일을 고치지 마세요. 게임을 끄고 고친 뒤 다시 켜세요.

## 문제 해결

| 증상 | 확인할 것 |
|------|-----------|
| 램프가 계속 **○ 게임 대기 중** | LMU **Settings → Gameplay → Enable Plugins**가 켜져 있는지, 켠 뒤 게임을 완전히 다시 시작했는지. 메뉴가 아니라 실제 세션(주행 화면)에 들어가 있는지. 그래도 안 되면 [rF2 공유 메모리 플러그인](#선택-rf2-공유-메모리-플러그인) 설치 (DLL 위치 `Plugins` 폴더, `" Enabled": 1` 공백 포함) |
| 상태에 "LMU 내장 공유 메모리의 값이 예상과 달라 쓰지 않습니다" | 게임 업데이트로 형식이 바뀐 듯. 잘못된 값으로 무전하지 않게 읽지 않는 중이에요 (Enable Plugins는 이미 켜져 있으니 다시 켤 필요 없어요). 고친 버전이 나올 때까지 [rF2 공유 메모리 플러그인](#선택-rf2-공유-메모리-플러그인)을 설치하면 알아서 그쪽으로 읽어요. 게임을 다시 시작하면(또는 일시정지처럼 5초 넘게 멈췄다 다시 달리면) 다시 확인하니 SimHub은 다시 켤 필요 없어요. 로그를 첨부해 알려 주세요 |
| 왼쪽 메뉴에 teamradio56이 없음 | DLL 두 개가 SimHub 폴더 **바로 아래**에 있는지. SimHub 재시작. **Settings → Plugins**에서 켜져 있는지 |
| 소리가 전혀 안 남 / 맨 위 빨간 안내 | 음성 팩이 없거나 받다 끊김 → **[음성 팩 업데이트]** (꺼져 있으면 먼저 **[업데이트 확인]**) |
| 음성 팩이 있는데 조용함 | **음성 출력**이 켜져 있는지, Windows 볼륨 믹서의 SimHub 볼륨, 기본 오디오 장치. **[테스트 발화]** 결과 확인 |
| 최근 무전에 `(무음)` | 음성 팩에 없는 멘트라 글자로만 낸 것 → 음성 팩 업데이트. 계속되면 로그 첨부해서 알려주세요 |
| 연습·퀄리에서 트래픽 콜이 없음 | **레이스에서만**이 기본으로 켜져 있음. 트랙을 같이 쓰는 세션이면 끄기 |
| 모니터·메뉴에서 조용함 | **주행 중에만 발화**가 켜져 있음 (정상) |
| 왼쪽·오른쪽이 반대 | **좌우 반전** 켜기 |
| 무전이 두 번 들림 | 예전 파이썬 단독 실행판이 같이 돌고 있음 → Steam 시작 옵션의 `launch_with_lmu.bat` 지우기, 작업 관리자에서 `python.exe`/`teamradio56.exe` 확인 |
| 업데이트 오류 "인터넷에 연결할 수 없습니다" | 오프라인·방화벽·프록시. 안 되면 릴리스 페이지에서 직접 받기 |
| 업데이트 오류 "릴리스 파일을 찾을 수 없습니다" | 새 릴리스를 올리는 중일 수 있어요. 조금 뒤에 다시 시도 |
| 업데이트 오류 "받은 파일이 손상되었습니다" | 다시 시도. 지금 쓰던 버전은 그대로 유지돼요 |
| 업데이트 오류 "폴더에 쓸 권한이 없습니다" | 업데이트할 때만 SimHub을 관리자 권한으로 실행하거나, 릴리스 페이지에서 받아 직접 설치 |
| 업데이트 뒤 플러그인이 안 뜸 | SimHub을 끄고 SimHub 폴더의 `teamradio56_backup.txt`를 열어, 줄마다 오른쪽 파일을 지우고 왼쪽 파일을 오른쪽 이름으로 바꾸기. 또는 이전 릴리스 DLL 복사 |
